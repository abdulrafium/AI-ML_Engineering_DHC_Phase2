# Auto Tagging Support Tickets Using LLM

## Objective

Automatically classify customer support tickets into relevant categories using Large Language Models (LLMs).

## Methodology

This project implements:

1. Zero-shot learning using BART LLM
2. Few-shot prompt engineering
3. Multi-class ticket classification
4. Top-3 tag prediction per ticket
5. Performance evaluation and visualization

## Technologies Used

Python  
Transformers (HuggingFace)  
Scikit-learn  
Matplotlib  
Seaborn  

## Results

• Zero-shot learning successfully classified tickets without training  
• Few-shot prompts improved prediction accuracy  
• Model outputs top 3 probable categories per ticket
