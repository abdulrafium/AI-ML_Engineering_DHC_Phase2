# News Topic Classifier Using BERT

## Objective
The objective of this project is to build a transformer-based NLP model that classifies news headlines into predefined categories using the AG News dataset.

## Dataset
AG News Dataset from Hugging Face.

Categories:
- World
- Sports
- Business
- Sci/Tech

## Methodology
1. Load dataset using HuggingFace Datasets
2. Tokenize text using BERT tokenizer
3. Fine-tune bert-base-uncased model
4. Evaluate using Accuracy and F1-score
5. Deploy using Gradio interface

## Results
The BERT model achieved high classification accuracy on the AG News dataset.

## Technologies Used
- Python
- HuggingFace Transformers
- PyTorch
- Scikit-learn
- Gradio
- Google Colab

## How to Run
1. Open the notebook in Google Colab
2. Install dependencies
3. Run all cells
4. Use the Gradio interface to test the model
